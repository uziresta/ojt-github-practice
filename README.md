# Git and Github

Git runs locally and provides version control, it tracks changes in your code and allows the user to runback to previous version.
GitHub runs online, same as Git but user can store and share repositories in the cloud.

# Commit

Commit is a saved update in the code. It contains the records of each commit. It usually contains message of the detail of the commit.
