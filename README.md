# Git and Github
Git is a version control. It lets the user to keep track of every change committed to the codebase. User can commit, review, and revert changes in the files. 
GitHub is a store service for Git repositories. It is a cloud-based platform where users can share repositories. 

# Commit
Commit is a saved update in the code. It contains the records of each commit. It usually contains message of the detail of the commit.
